Inventaire des outils de vibe coding

Comparaison de deux listes : un post publié sur X et le dépôt GitHub awesome-vibecoding. Page réalisée le 12 octobre 2026.

En bref

25ressources citées dans le post X (source A)
43outils dans la sélection principale du dépôt GitHub (source B)
0outil en commun entre les deux listes

Les deux sources se réclament du vibe coding, mais elles ne parlent pas de la même chose. Le post X recense des ressources pour soigner l'apparence d'un site : galeries d'inspiration, composants d'interface, animations. Le dépôt GitHub recense les outils qui écrivent, testent et déploient le code. Aucune des 25 ressources du post n'apparaît dans le dépôt, ni dans sa sélection principale ni dans son catalogue complémentaire.

4. Comparaison

Ce qui rapproche les deux sources

Presque rien sur le fond. Les seuls noms présents des deux côtés sont Claude, Cursor et Lovable, mentionnés dans la description du n°1 de la source A sans en faire partie. Les deux listes partagent surtout un mot, « vibe coding », qu'elles n'emploient pas dans le même sens.

Ce qui les distingue

La source A répond à la question « comment rendre beau un site généré par une IA ». La source B répond à « avec quels outils faire écrire, tester et mettre en ligne du code par une IA ». La source A est un contenu d'audience, publié pour être enregistré et partagé, avec un intérêt commercial direct de son auteur. La source B est un document de référence qui expose sa méthode, date ses vérifications et garde la trace de ce qu'il retire.

Fiabilité

Pour un inventaire des outils de vibe coding, la source B est nettement plus fiable. Elle n'est pas pour autant neutre ni infaillible. Ses propres auteurs précisent que la vérification porte sur l'existence de l'offre à une date donnée, et non sur un test ou un audit de sécurité. Sa mise à jour est en partie confiée à des agents IA. La version française est une traduction ajoutée dans une copie du dépôt, et c'est la version anglaise qui fait référence. Enfin, l'éditeur y fait figurer ses propres projets.

La source A garde un intérêt comme complément pour la partie design, à condition de vérifier chaque ressource et de garder en tête que l'auteur promeut son propre site.

5. Limites de ce travail

Les 25 ressources de la source A n'ont pas été testées une à une. Deux adresses n'ont pas pu être lues avec certitude sur la capture. Pour la source B, seule la copie publiée par Scap-Mehdi a été consultée, car c'est elle qui contient la version française ; le dépôt d'origine de Roboco peut avoir évolué depuis.
